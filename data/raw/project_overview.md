# Catcher LLM Project Overview

This project uses Streamlit for the user interface.

LangChain application logic lives under src/catcher_llm.

RAG source documents are stored in data/raw.

LangSmith dataset helpers and evaluation runners live under src/catcher_llm/evaluation.

The starter evaluation scripts are scripts/create_rag_eval_dataset.py and scripts/run_rag_eval.py.
