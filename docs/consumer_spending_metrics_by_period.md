# 소비 데이터 분석: 일일·주간·월간별 적합 지표

사람의 **소비 데이터**를 일일, 주간, 월간 단위로 나누어 분석할 때는 각 기간별로 적합한 지표가 다릅니다.  
같은 “총 소비금액”이라도 일일 단위에서는 **오늘 과소비했는지**, 주간 단위에서는 **생활 루틴이 어떤지**, 월간 단위에서는 **예산과 고정비 구조가 어떤지**를 보는 데 쓰입니다.

소비 데이터는 보통 다음 항목을 포함한다고 가정합니다.

```text
거래일시, 금액, 카테고리, 가맹점, 결제수단, 지역, 할인 여부
```

## 기간별 분석 목적

| 기간 | 분석 목적 | 적합한 지표 성격 |
|---|---|---|
| 일일 | 즉각적인 소비 행동, 이상 소비, 습관 탐지 | 빈도, 시간대, 이상치, 당일 예산 |
| 주간 | 생활 패턴, 루틴, 주중·주말 차이 | 요일 패턴, 주말 소비, 카테고리 흐름 |
| 월간 | 예산 관리, 고정비, 소비 구조, 장기 추세 | 고정비, 예산 대비, 전월 대비, 구독료 |

# 1. 일일 소비 분석에 적합한 지표 10개

일일 지표는 **하루 안에서 소비가 어떻게 발생했는지**를 보는 데 적합합니다.  
장기적인 판단보다는 “오늘의 소비 행동”과 “이상 징후”를 보는 데 좋습니다.

| 지표 | 설명 | 활용 예시 |
|---|---|---|
| 1. 일일 총 소비금액 | 하루 동안 사용한 총금액 | 오늘 85,000원 소비 |
| 2. 일일 거래 건수 | 하루 동안 결제한 횟수 | 오늘 7회 결제 |
| 3. 일일 평균 거래금액 | 일일 총 소비금액 ÷ 거래 건수 | 하루 평균 결제 단가 파악 |
| 4. 일일 최대 결제금액 | 하루 중 가장 큰 결제금액 | 갑작스러운 고액 소비 탐지 |
| 5. 시간대별 소비금액 | 아침, 점심, 저녁, 야간 소비 구분 | 야간 배달 소비가 많은지 확인 |
| 6. 야간 소비 비중 | 밤 10시 이후 소비금액 ÷ 일일 총 소비금액 | 충동소비, 음주, 배달 패턴 분석 |
| 7. 일일 카테고리별 소비 | 하루 동안 식비, 교통, 쇼핑 등에 쓴 금액 | 오늘 식비가 과도했는지 확인 |
| 8. 일일 예산 소진율 | 일일 소비금액 ÷ 일일 목표 예산 | 하루 예산 30,000원 중 45,000원 사용 |
| 9. 무소비일 여부 | 해당 날짜에 소비가 있었는지 여부 | 소비 절제 습관 분석 |
| 10. 일일 이상 소비 점수 | 평소 일일 소비 패턴과 비교한 이상치 점수 | 평소보다 3배 이상 지출한 날 탐지 |

## 일일 분석에서 특히 좋은 특수 지표

### 1) 충동소비 추정 지표

야간, 주말, 쇼핑, 배달, 고빈도 소액결제 등을 조합해서 만들 수 있습니다.

```text
충동소비 점수 =
야간 소비 비중 × 0.3
+ 비필수 카테고리 소비 비중 × 0.4
+ 평소 대비 거래 건수 증가율 × 0.3
```

### 2) 하루 소비 위험도

오늘 소비가 평소보다 얼마나 위험한지 보는 지표입니다.

```text
하루 소비 위험도 = 오늘 소비금액 ÷ 최근 30일 일평균 소비금액
```

예를 들어 최근 30일 일평균 소비가 40,000원인데 오늘 120,000원을 썼다면 위험도는 **3.0배**입니다.

# 2. 주간 소비 분석에 적합한 지표 10개

주간 지표는 **생활 패턴과 루틴**을 보는 데 적합합니다.  
일일 데이터보다 안정적이고, 월간 데이터보다 행동 변화를 빠르게 볼 수 있습니다.

| 지표 | 설명 | 활용 예시 |
|---|---|---|
| 1. 주간 총 소비금액 | 한 주 동안 사용한 총금액 | 이번 주 420,000원 소비 |
| 2. 주간 평균 일 소비금액 | 주간 총 소비금액 ÷ 7일 | 하루 평균 소비 수준 파악 |
| 3. 주간 거래 건수 | 한 주 동안 발생한 결제 횟수 | 이번 주 35회 결제 |
| 4. 주중 소비 비중 | 월~금 소비금액 ÷ 주간 총 소비금액 | 평일 생활비 소비 분석 |
| 5. 주말 소비 비중 | 토~일 소비금액 ÷ 주간 총 소비금액 | 주말 외식·여가 소비 분석 |
| 6. 요일별 소비 패턴 | 월~일 각각의 소비금액 비교 | 금요일과 토요일 소비가 높은지 확인 |
| 7. 주간 카테고리별 소비 | 식비, 교통, 쇼핑 등 주간 카테고리 소비 | 이번 주 식비가 많이 나갔는지 확인 |
| 8. 전주 대비 소비 증감률 | 이번 주 소비 ÷ 지난주 소비 - 1 | 전주보다 20% 증가 |
| 9. 주간 소비 변동성 | 7일간 소비금액의 표준편차 | 소비가 고르게 발생했는지, 특정일에 몰렸는지 확인 |
| 10. 주간 예산 소진율 | 주간 소비금액 ÷ 주간 예산 | 주간 예산 300,000원 중 360,000원 사용 |

## 주간 분석에서 특히 좋은 특수 지표

### 1) 주말 과소비 지수

주말에 소비가 과도하게 몰리는지 보는 지표입니다.

```text
주말 과소비 지수 =
주말 1일 평균 소비금액 ÷ 주중 1일 평균 소비금액
```

예를 들어 주중 하루 평균 소비가 30,000원이고 주말 하루 평균 소비가 90,000원이면 주말 과소비 지수는 **3.0**입니다.

### 2) 소비 요일 편중도

소비가 특정 요일에 집중되는지 보는 지표입니다.

예를 들어 금요일과 토요일 소비가 전체 주간 소비의 60% 이상이면, 소비가 특정 요일에 강하게 몰려 있다고 볼 수 있습니다.

### 3) 생활 루틴 지표

매주 반복되는 소비 패턴을 찾는 지표입니다.

```text
월~금 교통비 반복 발생
화·목 카페 소비 반복 발생
토요일 외식 소비 반복 발생
```

이런 패턴은 개인의 생활 리듬, 출근 여부, 운동, 외식 습관 등을 추정하는 데 사용할 수 있습니다.

# 3. 월간 소비 분석에 적합한 지표 10개

월간 지표는 **예산 관리, 고정비, 소비 구조, 장기 추세**를 보는 데 가장 적합합니다.  
소비 분석에서 가장 중요한 단위라고 볼 수 있습니다.

| 지표 | 설명 | 활용 예시 |
|---|---|---|
| 1. 월간 총 소비금액 | 한 달 동안 사용한 총금액 | 4월 총 소비 1,850,000원 |
| 2. 월간 예산 대비 사용률 | 월간 소비금액 ÷ 월간 예산 | 예산 2,000,000원 중 92.5% 사용 |
| 3. 전월 대비 소비 증감률 | 이번 달 소비 ÷ 지난달 소비 - 1 | 전월 대비 15% 증가 |
| 4. 고정비 금액 | 월세, 통신비, 보험료, 구독료 등 반복 지출 | 매월 반드시 나가는 비용 파악 |
| 5. 고정비 비중 | 고정비 ÷ 월간 총 소비금액 | 전체 소비 중 고정비가 45% |
| 6. 변동비 금액 | 식비, 쇼핑, 여가 등 조절 가능한 지출 | 줄일 수 있는 소비 영역 파악 |
| 7. 카테고리별 월간 소비 비중 | 카테고리별 소비 ÷ 월간 총 소비 | 식비 28%, 쇼핑 15%, 교통 8% |
| 8. 구독료 합계 | OTT, 앱, 멤버십, 정기결제 총액 | 불필요한 정기결제 탐지 |
| 9. 급여일 이후 소비 증가율 | 급여일 직후 소비가 평소보다 얼마나 증가했는지 | 월급 직후 과소비 패턴 확인 |
| 10. 월말 소비 압박 지수 | 월말에 소비가 줄거나 카드 사용이 늘어나는 패턴 | 자금 부족, 예산 초과 가능성 분석 |

## 월간 분석에서 특히 좋은 특수 지표

### 1) 고정비 부담률

소득 데이터가 있다면 매우 중요한 지표입니다.

```text
고정비 부담률 = 월간 고정비 ÷ 월 소득
```

예를 들어 월 소득이 300만 원이고 고정비가 120만 원이면 고정비 부담률은 **40%**입니다.

### 2) 소비 여력 지표

월말에 돈이 얼마나 남을 수 있는지 보는 지표입니다.

```text
소비 여력 = 월 소득 - 고정비 - 필수 변동비
```

이 지표는 단순 소비 분석보다 재무 관리에 더 가깝습니다.

### 3) 구독 누수 지표

소액 정기결제가 계속 빠져나가는지 보는 지표입니다.

```text
구독 누수율 = 사용 빈도가 낮은 구독료 ÷ 전체 구독료
```

예를 들어 월 구독료가 80,000원인데 거의 쓰지 않는 서비스가 45,000원이라면 구독 누수율은 **56.25%**입니다.

# 4. 기간별 핵심 질문

## 일일 지표의 핵심

일일 지표는 **소비 행동 감지용**입니다.

좋은 질문은 다음과 같습니다.

```text
오늘 평소보다 많이 썼는가?
오늘 소비가 특정 시간대에 몰렸는가?
오늘 갑자기 큰 결제가 있었는가?
오늘 무소비일인가?
오늘 예산을 초과했는가?
```

그래서 일일 지표는 다음 성격이 적합합니다.

```text
즉시성
이상치 탐지
소비 빈도
시간대 분석
무소비일 판단
```

## 주간 지표의 핵심

주간 지표는 **생활 패턴 분석용**입니다.

좋은 질문은 다음과 같습니다.

```text
이번 주 소비가 지난주보다 늘었는가?
주말에 소비가 몰렸는가?
특정 요일에 소비가 반복되는가?
이번 주 식비나 외식비가 과했는가?
주간 예산을 넘었는가?
```

그래서 주간 지표는 다음 성격이 적합합니다.

```text
요일별 패턴
주중·주말 차이
전주 대비 변화
생활 루틴
주간 예산 관리
```

## 월간 지표의 핵심

월간 지표는 **재무 구조 분석용**입니다.

좋은 질문은 다음과 같습니다.

```text
이번 달 예산을 초과했는가?
고정비가 너무 높은가?
소비가 어떤 카테고리에 치우쳐 있는가?
전월보다 소비가 늘었는가?
구독료가 불필요하게 빠져나가고 있는가?
```

그래서 월간 지표는 다음 성격이 적합합니다.

```text
예산 관리
고정비 분석
전월 대비 변화
소비 구조 분석
구독 및 반복 지출 관리
```

# 5. 같은 지표라도 기간별 해석이 달라짐

| 지표 | 일일 해석 | 주간 해석 | 월간 해석 |
|---|---|---|---|
| 총 소비금액 | 오늘 과소비 여부 | 이번 주 소비 흐름 | 월 예산 관리 |
| 거래 건수 | 잦은 결제 여부 | 생활 루틴 확인 | 소비 빈도 성향 |
| 카테고리별 소비 | 오늘 무엇에 썼는지 | 이번 주 생활패턴 | 월간 소비 구조 |
| 증감률 | 어제보다 늘었는지 | 지난주보다 늘었는지 | 전월 대비 변화 |
| 예산 소진율 | 하루 예산 초과 여부 | 주간 예산 관리 | 월간 예산 관리 |
| 이상 소비 | 갑작스러운 고액 결제 | 특정 주 소비 급증 | 비정상적인 월간 지출 |

# 정리

소비 데이터 분석에서는 모든 지표를 모든 기간에 똑같이 적용하기보다는 목적에 맞게 나누는 것이 좋습니다.

```text
일일 분석 = 행동 탐지
주간 분석 = 생활 패턴 분석
월간 분석 = 예산과 소비 구조 분석
```

따라서 **일일은 즉각적인 소비 행동과 이상 징후**, **주간은 생활 루틴과 요일별 패턴**, **월간은 예산·고정비·소비 구조**에 초점을 두는 것이 가장 좋습니다.
